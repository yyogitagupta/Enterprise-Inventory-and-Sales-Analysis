# Enterprise Inventory and Sales Analysis Using Excel

## Project Overview
This project focuses on analyzing sales performance and inventory levels using Microsoft Excel. It demonstrates how raw sales and inventory data can be organized, cleaned, analyzed, and transformed into meaningful business insights through Excel formulas, data analysis, charts, and a dashboard.
The workbook includes raw datasets, cleaned data, inventory calculations, revenue analysis, and dashboard visualizations to support business decision-making.

## Business Objectives
The main objectives of this project are to:
* Analyze sales performance across different regions and sales channels.
* Calculate revenue generated from product sales.
* Monitor inventory levels and identify products that may require replenishment.
* Organize and clean raw sales and inventory data.
* Summarize key business metrics for easier interpretation.
* Present important findings through a visual Excel dashboard.

## Dataset Description
The workbook contains sales transaction records and product inventory information.

### 1. Raw Sales Data
Contains the original sales transaction records, including:
* Transaction ID
* Date
* Product ID
* Quantity Sold
* Region
* Sales Channel

### 2. Cleaned Sales Data
Contains the prepared sales dataset along with additional calculated fields used for analysis, including date-related fields and revenue calculations.

### 3. Raw Inventory Master
Contains the original product information, including:
* Product ID
* Product Name
* Category
* Unit Cost
* Selling Price
* Safety Stock Level
* Starting Stock

### 4. Cleaned Inventory Master
Combines product information with calculated inventory and sales metrics, including total units sold, ending inventory, and gross revenue.

### 5. Analysis and Dashboard
Contains dashboard visualizations and supporting analysis sheets for examining revenue trends, sales channels, and inventory status.

## Project Workflow
The project follows a structured data analysis workflow:
1. **Data Collection:** Review the raw sales transaction and inventory datasets.
2. **Data Cleaning:** Prepare the datasets for analysis by addressing inconsistencies in the source data.
3. **Data Transformation:** Create calculated fields for dates, revenue, and other analytical requirements.
4. **Sales Analysis:** Examine sales performance by month, region, product, and sales channel.
5. **Inventory Analysis:** Calculate units sold and ending inventory to help assess stock availability.
6. **Data Visualization:** Summarize important metrics using charts and dashboard elements.
7. **Business Insights:** Use the analysis to identify sales trends and potential inventory replenishment needs.

## Key Metrics
The workbook supports analysis of the following metrics:
* **Total Units Sold:** Total quantity of products sold.
* **Revenue:** Revenue calculated from product sales.
* **Monthly Revenue:** Revenue summarized by month.
* **Sales Channel Revenue:** Revenue generated through online, in-store, and wholesale channels.
* **Ending Inventory:** Starting stock minus recorded units sold.
* **Inventory Status:** Product stock status used to identify items that may require replenishment.
